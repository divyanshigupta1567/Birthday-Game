# 🎂 Birthday Date Guessing Game

A fun and interactive web-based game that guesses the user's **birth date** through a series of simple questions. The game uses a logical number-selection approach to identify the possible date based on the user's responses.

## ✨ Features

* 🎯 Interactive birthday date guessing experience
* 📅 Guesses the user's birth date through simple choices
* 🧠 Uses logical calculations to determine the selected date
* 🎨 Clean and user-friendly interface
* 📱 Responsive design for different screen sizes
* ⚡ Fast and lightweight — runs directly in the browser
* 🔄 Allows users to play the game again

## 🛠️ Technologies Used

* **HTML5** – Structure of the game
* **CSS3** – Styling, layout, and visual design
* **JavaScript** – Game logic, calculations, and user interaction

## 🎮 How to Play

1. Open the game in your browser.
2. Follow the questions displayed on the screen.
3. Select the appropriate option based on your birth date.
4. Continue through all the steps.
5. At the end, the game calculates and displays your **birth date**. 🎉

## 💡 How It Works

The game is based on a mathematical pattern rather than randomly guessing the birthday.

Each response provides information about the possible date. JavaScript processes these responses and uses the underlying logic to narrow down the possibilities until the correct birth date can be determined.

This makes the project a simple example of how **mathematical logic and JavaScript programming** can be combined to create an interactive web application.
